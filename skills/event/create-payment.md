# create_payment — 创建支付

> 参数已按 2026-09-16 tools/list 实测 schema 校准。

## 用途

为已报名的活动订单创建微信支付单。**高风险操作，必须二次确认金额。**

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | string | 二选一 | 报名返回的订单 ID |
| activity_id + phone | string | 二选一 | 无订单号时，用活动 ID + 报名手机号定位订单 |

## 调用示例

```json
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"create_payment","arguments":{"order_id":"ord_123"}}}
```

## 返回

支付信息：支付方式（小程序内拉起微信支付）、金额、状态。

## 注意

- 调用前向用户确认金额（"¥58，确认支付吗"）
- 支付单创建失败或用户取消后，**同一订单重试必须再次确认**，绝不静默重试
- 支付类接口任何异常都直接转述错误信息并停止，不要连续调用
- 实际付款动作在粗趣小程序内完成，Agent 负责创建支付单并告知用户去向
